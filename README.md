# 🚀 Swift Lab

This repository contains:

- 📱 **Xcode Projects** (`.xcodeproj`)
- 💻 **Standalone Swift Code Files**

---

## 📂 How to Run Xcode Projects

1. Open the `.xcodeproj` file using **Xcode**
2. Navigate to the **Storyboard** to explore the UI
3. Use the **Assistant Editor** to view related Swift code
4. Click the **Run (▶)** button to build and simulate the app

---

## 💻 How to Run Swift Code Files

You can run standalone Swift files using:

### 👉 Option 1: Xcode
- Open the file in Xcode  
- Run it inside a project or Playground  

### 👉 Option 2: Terminal
```bash
swift filename.swift
