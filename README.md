🚀 Swift Lab

This repository contains:

📱 Xcode Projects (.xcodeproj)


💻 Standalone Swift Code Files


📂 How to Run Xcode Projects


Open the .xcodeproj file using Xcode


Navigate to the Storyboard to explore the UI


Use the Assistant Editor to view related Swift code


Click the Run (▶) button to build and simulate the app


💻 How to Run Swift Code Files

You can run standalone Swift files using:

👉 Option 1: Xcode


Open the file in Xcode


Run it inside a project or Playground


👉 Option 2: Terminal


swift filename.swift


⚠️ Requirements


🍎 macOS (Required for Xcode projects)


🛠 Xcode installed


⚡ Swift compiler (for CLI execution)


📌 Notes


Xcode projects only run on macOS


Swift files can run on macOS or Linux (with Swift installed)
